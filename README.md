# 💪 Дневник тренировок — Workout Diary

Персональное PWA-приложение для ведения дневника тренировок. Разработано под конкретного пользователя с учётом ДНК-теста MyWellness, травмы колена и целей по снижению веса.

**Живая версия:** https://klemon46124-design.github.io/workout-diary/

**Сервисы:**
- Authentication → Email/Password
- Firestore → europe-west

**Правила безопасности** — доступ только к своему документу:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      match /{document=**} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
}
```

## 📱 Функциональность

### Дневник тренировок
- Создание тренировок из пользовательских шаблонов
- Отметка подходов с возможностью добавить лишние
- Ввод веса кнопками ±2.5 кг
- Автодополнение названий из истории
- Плановые веса и повторы подсказкой
- Аналоги упражнений с автоподстановкой схемы
- Перемещение упражнений ▲▼
- Сравнение с прошлой тренировкой
- Оценка одноповторного максимума рядом с весом
- Редактирование завершённых тренировок и возврат их в работу
- Удаление в корзину на 30 дней

### Режим тренировки
Полноэкранный режим для зала: крупное название упражнения, кнопки подходов во всю ширину, вес с большими ±, переключение упражнений стрелками.

- **🔆 Wake Lock** — экран не гаснет, пока режим открыт
- **🔒 Экран блокировки** — эксперимент: приложение проигрывает беззвучный трек, iOS показывает карточку «плеера» с текущим упражнением и счётчиком подходов; кнопки ⏭ / ⏮ отмечают и отменяют подход. Выключено по умолчанию — включение ставит на паузу твою музыку. Safari поддерживает это нестабильно.

### Таймер
- Фиксирован внизу экрана и продублирован в режиме тренировки
- Пресеты: 60с / 75с / 90с / 3м
- Считает от метки времени, поэтому переживает блокировку экрана
- Звуковой сигнал по окончании
- Запускается вручную; автоматически — только при отметке подхода с экрана блокировки

### Кардио
- Велосипед / Бег / Ходьба
- Кнопка «⚡ Как обычно» подставляет медиану последних заездов того же типа
- График и статистика

### Трекер веса
- Поле предзаполняется последним значением, кнопки ±100 г
- График с линией цели (90 кг) и прогресс-бар
- История с динамикой

### Аналитика
- Прогресс текущей недели
- Общая статистика, личные рекорды
- График прогресса: **рабочий вес** или **оценка 1ПМ** по формуле Эпли
- Долгосрочная динамика по месяцам, скорость прогресса в кг/мес
- Сравнение текущего месяца с прошлым

### Обслуживание данных
- **Объединение упражнений** — приложение находит разные написания одного упражнения и предлагает склеить историю
- Резервная копия с проверкой структуры при восстановлении
- Корзина с обратным отсчётом до автоудаления

### Фазы тренировок
- Тр. 1–12: базовая фаза, линейная прогрессия
- Тр. 12: 🟢 баннер — переход на восстановление
- Тр. 13–15: восстановительная неделя (60% весов автоматически)
- Тр. 16+: 🟣 Фаза 2, волновая периодизация — тяжёлая → средняя → лёгкая неделя по кругу, +2.5 кг за круг

## 📶 Офлайн-режим

Приложение полностью работает без связи:

- Service Worker кэширует само приложение **и внешние библиотеки** (Firebase SDK, Chart.js) — без них офлайн не запустился бы вообще
- Запросы к Firestore и авторизации в кэш не попадают никогда
- Открытие идёт по схеме «сначала сеть»: со связью подтягивается свежая версия, без связи — сохранённая копия
- Данные пишутся в `localStorage` **до** обращения к сети, а Firestore-персистентность хранит очередь записей в IndexedDB
- Статус синхронизации в шапке: ✓ сохранено · ⟳ идёт · ✗ ошибка · 📴 офлайн

**Проверка:** открой сайт со связью и дай ему загрузиться, затем включи авиарежим и запусти приложение с иконки.

## 🏋️ Программа тренировок

Фулбади 3×неделю, велосипед Вт/Чт.

**Тренировка A:**
Присед 5×5 · Жим лёжа 5×5 · Тяга в наклоне 15×4 · Разводка стоя 15×3 · Бицепс 15×3 · Планка 3×60с

**Тренировка B:**
Становая 5×5 · Тяга блока 15×4 · Жим на наклонной 15×3 · Обратная разводка 15×3 · Сгибания ног 15×3 · Трицепс 15×3 · Пресс 15×3

**Тренировка C:**
Румынская 15×4 · Разгибания ног 15×2 · Брусья 15×4 · Разводка лёжа 15×3 · Хаммер одной рукой 15×3 · Тяга к подбородку 15×3 · Фермерская 3×40м

Формат записи: повторения×подходы.

## 🚀 Деплой

### GitHub Pages
1. Залей файлы в репозиторий `workout-diary`
2. Settings → Pages → Deploy from branch → main
3. Сайт доступен по адресу `https://{username}.github.io/workout-diary/`

### Обновление
1. Скачай новые файлы
2. Залей на GitHub через Add file → Upload или редактор
3. Подожди 1–2 минуты — GitHub Pages обновится автоматически

Меняешь `sw.js` — подними версию кэша в первой строке (`wd-v2` → `wd-v3`), иначе у устройств останется старый набор файлов.

### Сброс кэша на телефоне
- Удали приложение с главного экрана
- Открой Safari → зайди на сайт → Поделиться → На экран «Домой»

### Перед обновлением
Сделай резервную копию: ⚙️ Ещё → Резервная копия → Копировать. При первом запуске новой версии миграции переписывают данные и сразу сохраняют их в облако.

## ⚠️ Известные ограничения

- Оценка 1ПМ берёт **плановые** повторы, а не фактические, и сама формула даёт разброс 5–10% — годится для тренда, не для абсолютных чисел
- Тоннаж приблизителен: вес один на все подходы, разминочные не отделены
- Упражнения со своим весом (подтягивания, брусья) вносят в объём ноль
- Управление с экрана блокировки — эксперимент, Safari может не отдавать нажатия
- Интеграции с Apple Health нет — веб-приложению доступ закрыт
- Напоминаний по расписанию нет — нужен сервер
